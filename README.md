## About The Project

**Webku** adalah website jasa pembuatan website yang dirancang untuk membantu UMKM dan bisnis membangun kehadiran digital yang profesional.

Website ini menyediakan informasi mengenai berbagai paket pembuatan website, layanan desain pendukung, artikel edukasi, FAQ, testimoni, serta konsultasi langsung melalui WhatsApp.

Fokus utama Webku adalah menyediakan informasi layanan secara jelas dan membantu calon pelanggan menemukan solusi website yang sesuai dengan kebutuhan bisnis mereka.

## Installation

Clone repository:

```bash
git clone https://github.com/your-username/webku.git
```

Masuk ke folder project:

```bash
cd webku
```

Install dependencies:

```bash
npm install
```

atau menggunakan Yarn:

```bash
yarn install
```

---

## Run Development Server

Jalankan development server:

```bash
npm run dev
```

Kemudian buka:

```text
http://localhost:3000
```

---

## Build for Production

Untuk membuat production build:

```bash
npm run build
```

Kemudian jalankan:

```bash
npm run start
```

## Available Scripts

| Command                 | Description                                               |
| ----------------------- | --------------------------------------------------------- |
| `npm run dev`           | Menjalankan development server                            |

| `npm run build`         | Membuat production build                                  |
| `npm run start`         | Menjalankan production server                             |
